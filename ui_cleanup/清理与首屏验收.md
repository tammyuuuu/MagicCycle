# 星循旧UI清理与首屏修复验收

## 根因与实测

旧静态和动态入口在head先装入1168px宽屏/双列规则，460px窄屏覆盖放在body末尾，中间隔着大型版本化研究数据和同步脚本。浏览器分段接收HTML时可先按旧规则绘制，直到收到末尾样式才缩窄。没有发现应用JS主动修改body宽度。

本机测试服务器将HTML分两段发送，相隔1.8秒，以每帧采样记录header出现后的body宽度：

| 视口 | 清理前首个宽度 → 最终 | 修复后首个宽度 → 最终 |
|---|---|---|
| 1440px | 1440 → 460 | 460 → 460 |
| 375px | 375 → 375 | 375 → 375 |
| 320px | 320 → 320 | 320 → 320 |

修复版还逐个验证了禁用JavaScript、刷新与四页切换。无隐藏body、加载遮罩或宽度过渡；旧页面进入动画也已移除。

## 加载关系与清理

当前链路：`app.py → templates/index.html → _styles.html（head）＋_status_rail.html（信号交互）＋_invest_tools.html（当前组件）`；`export_alerts.py`复用同一head样式及组件，通过`correlation_data.py`装配当前store、资金池、估值、规划器、策略图表、工作区与购买监测。

- 删除`templates/_mobile_ui.html`这个末尾覆盖文件，现有有效样式移入`templates/_styles.html`。
- 移除两份重复宽屏基础样式、760/600px旧布局分支、1120/1168px宽度、双列ETF布局和旧桌面导航覆盖。
- 从`_status_rail.html`与`_invest_tools.html`移出重复内嵌CSS；动态和静态入口均从5个样式块改为head内1个，body内0个。
- 删除动态入口隐藏的参数编辑/规则编辑/旧条件定投回测HTML，以及其构建表单、渲染规则、旧表格和回测展示JS。
- 删除正式导出器旧式ETF持仓卡片分支、REPS/CODES/LABEL及旧持仓编辑/判断/回填脚本；当前调用链始终提供新版summary或明确error，不再进入旧卡片路径。
- 删除未调用的表格辅助函数、旧双策略比较别名和旧导航包装；底部导航由当前工作区统一绑定。
- 从app首页移除无任何挂载位置的旧研究指南生成调用。
- 更新`run_tests.py --browser`指向当前五组验收，不再依赖旧双策略/旧配置界面的浏览器选择器；修正美股监测测试桩对现有事件及dataset的支持。
- 更新PWA缓存版本；增强测试以覆盖淘汰旧缓存、离线首帧及离线四页切换。

主要修改文件：`templates/_styles.html`、`templates/index.html`、`templates/_status_rail.html`、`templates/_invest_tools.html`、`export_alerts.py`、`investment_workspace.js`、`app.py`、`docs/sw.js`、`run_tests.py`、`test_purchase_monitor.js`、`maintenance/20261022/test_pwa.js`、`README.md`；正式HTML/JSON由原导出器生成。核心策略、账本、估值、规划器与版本化回测结果未改。

## PWA判断

首屏问题可在阻止Service Worker的全新上下文复现，因此PWA缓存不是根因。样式原本内嵌于HTML，不存在单独CSS文件跨版本拼接。新版关键样式与HTML同响应原子缓存，缓存版本提升至`magiccycle-pwa-v6-head-styles`。已验证旧缓存被删除，新版离线启动保持460px布局。

## 仍保留的旧依赖

生产页面不再加载旧宽屏、旧投资日记、旧月预算或旧相关性UI模块。

- `archive/legacy_ui/correlation_tools.js`：`test_correlation_tools.js`仍读取。
- `archive/legacy_ui/investment_tools.js`：`test_journal_integration.js`与`test_strategy_preferences.js`仍读取，以保护修复过的账本与信号兼容行为。
- `archive/legacy_ui/monthly_budget.js`：`test_monthly_budget.js`仍读取。
- 旧归档模板和历史验收资料还受`test_maintenance.py`的归档哈希审计保护，未破坏归档。
- `asset_states.render_guide()`由ETF策略研究测试直接验证；仅停止在当前首页无意义地调用，不删除研究函数。
- `/api/backtest`、`/api/save`、`/api/decide`等后端兼容接口保留，未因删除不可达前端而改变核心能力。
- 当前store中的旧存储只读识别、备份恢复适配保留；不恢复旧日记界面，也不删除用户本地存储。

## 验收结果

- 核心统一入口15组全部通过，含185个根目录Python测试及全部既有Node/资金池测试与保护数据检查。
- 当前UI入口5组全部通过，每组覆盖1440/375/320px：ETF分类与五档信号、美股监测、配置完整交易生命周期、账本冻结/确认/赎回/幂等/撤销更正/资金流/JSON恢复、复盘月份与计算、策略实验逐日数据/缺失数据/图例联动。
- 动态Flask入口三种宽度通过：head单一样式、旧表单不存在、数据载入、分类保持、四页切换，无横向溢出或未捕获JS错误。
- 分段加载冷启动、刷新、页面切换及禁用JS布局三种宽度通过。
- PWA真实安装、旧缓存淘汰、离线重载、离线首帧宽度及四页导航通过。
- 未发现阻断性产品回归。测试过程中发现的旧测试桩和缓存测试服务器空路由问题均已修正并通过复测。
