| 情况 | 目标配置 | 实际可买 | 建仓完成时间 | 费用（纳指腿） | 建议 |

**切换流程（K4 → B）**

1. 确认 161130 在你的渠道可买、额度 ≥ 666.67 元（或按可用额度分批）。
2. 先买入纳指（用池内现金/货币基金），不要先卖后买（避免空仓等待）。
3. 若现金不足：卖出部分纯债（持有 ≥30 天赎回费 0）与少量黄金，卖出款 **T+2 到账后再买纳指**；不要用未到账的钱下单。
4. 切换后按 B 的 1/3 权重月度再平衡；切换当月不要反复调整。
5. 若额度只恢复到 100 元/日：分 7 个交易日买入，期间其余资金留货基，不做其他调仓。

**切换成本（实测）**：5 个起点平均费用 3.42–3.51 元（vs 一直 B 2.16 元），额外约 1.3–1.6 元；持有 30 天切换的额外成本约 0.09% 本金。

**不做什么**：不因为额度短暂变化反复切换；不把 A 股/黄金当纳指替代（V2.0 已证明更差）；不假设"明天一定恢复"。

## 6. 日常管理规则

| 事项 | 规则 |
| --- | --- |
| 每日检查 | **不需要每天计算**。网站/表格显示"无需操作"即可；只有持仓或限购状态变化时才看 |
| 权重检查 | 每月首个交易日检查一次；单只偏离目标 >2pp 才调（2% 带），单笔 <10 元不交易 |
| 再平衡 | 卖出超配、买入低配；卖出款 T+2 到账后再买；优先用新增现金补低配，减少卖出 |
| 新增资金 | 每月总资产更新后，新增额度按目标权重分配，随下一次月度检查一起买；不追涨、不分批 |
| 卖出 | 只在三种情况卖出：再平衡、基金替换（需验证）、限购切换。**不做止盈止损**；持有 <7 天不卖 |
| 现金 | 未投入/在途资金放货币基金（000198 或支付宝余额宝），不买短债替代现金 |
| 限购 | 暂停/限额不足 → 对应资金留货基，不自动替换；恢复到 ≥100 元/日再补 |
| 记录 | 每笔成交当天记入投资日记（代码、金额、净值、份额、费用），确认份额到账后补录 |

## 8. 月度复盘数据流程

| 字段 | 来源 | 口径 |
| --- | --- | --- |
| 月初/月末资金池资产 | 快照 + 持仓市值 + 现金 + 在途 | 只算新策略账户，不含历史持仓 |
| 本月流入/流出 | 手动记录 | 入金/出金，不计入收益 |
| 本月盈亏 | 月末 − 月初 − 净流入 | 含未卖出浮盈浮亏 |
| 本月收益率 | 盈亏 / 月初资产 | 与资金流入分开 |
| 持仓市值 / 现金 / 在途 | 日记 + 份额确认 | 未确认份额不计入 |
| 交易次数 / 手续费 | 投资日记 | 含申购与赎回费 |
| 本月最大回撤 | 日度净值（需补记录） | 网站暂无，先用月末序列近似 |
| 策略模拟收益 | 同一资金池按规则模拟 | 网站暂无 |
| 基准收益 | 建议：50% 货基 + 50% 纯债；或等权四只 | 网站暂无 |

旧持仓与新策略**分开统计**；历史持仓只计入总金融资产（用于 10% 池子），不产生买卖建议。
