## 0. 最终结论（一句话）

在 2000 元投资池、场外基金、真实费率、T+1 确认 / T+2 到账的约束下：

> **唯一没有被数据否定的方案是"逆波动率加权配置 + 买入持有 + 10% 资金池 + 货币基金现金"，择时策略只保留影子记录。**

> 命名更正：第四轮初稿把该方案称为"风险平价"，但实现是**简单逆波动率加权（w∝1/σ）**，未使用协方差矩阵。
> 本文已更正；另用同一数据、费用与样本外区间做了完整协方差 ERC 对照（见 4.6），结论是**不采用 ERC**，保留简单方案。

逆波动率四资产（债券上限 40%）在 2019-03 ~ 2026-10 的样本外表现：

| 指标 | 数值 |
|---|---|
| 年化收益 | 10.86% |
| 最大回撤 | −5.81% |
| Sharpe（对货基） | 1.21 |
| Calmar | 1.87 |
| 7.6 年交易次数 | 96 笔（累计费用 9.65 元） |

这不是收益最高的方案（30/35/15/20 的样本外年化 13.12%），但**回撤只有它的一半、风险调整后收益明显更高**，符合"组合稳定性优先"的原则。

## 1. 数据基础（第一轮）

- 8 只场外基金，真实单位净值 + 现金分红再投资，合计 26,000+ 个净值日。
- 原始快照 `raw/`（SHA256 + 抓取时间），清洗结果 `clean/`。
- 数据质量：重复 0、非正净值 0、与数据源自带日收益交叉校验不一致天数 0。
- 区间：全资产 2019-03-08 ~ 2026-10-21（7.3 年）；长期面板 2013-08-22 起（4 资产）。

**必须记住的口径**：

| 项 | 口径 |
|---|---|
| 收益 | `(NAV_t + 现金分红_t) / NAV_{t-1} − 1`，分红按除息日再投资 |
| 净值日 | 是"净值日期"，不是下单时间 |
| 场外交易 | T 日 15:00 前下单 → 按 T 日未知净值确认；T+1 确认份额；赎回 T+1 确认、T+2 到账 |
| 费率 | 申购 0.04%–0.15%；7 天内赎回 1.5%；1 年以上 0–0.5% |

**未核实**：支付宝/微信渠道的可购状态、实际折扣、渠道限额。所有"可买"结论只到基金层面。

## 2. 资产互补性（第一轮）

| 关系 | 长期日相关 | 结论 |
|---|---|---|
| 黄金–沪深300 | 0.05 | 接近零相关，但当前 250 日已升到 0.41（历史最高 0.46） |
| 债券–沪深300 | −0.13 ~ −0.23 | 真正的负相关资产 |
| 沪深300–中证500 | 0.85 | 同一风险源，互不分散 |
| 沪深300–中证红利 | 0.70–0.84 | 红利不是独立风险源 |
| 三只债券基金之间 | 0.64–0.90 | 同时持有 = 重复买同一风险 |

**危机表现**：

- 2015 股灾（−42.7%）：黄金 +1.14%，债券未纳入样本。
- 2021–2024 长熊（−39.5%）：黄金 +23.9%，红利 +21.5%，7-10年国开 +17.7%。
- 沪深300 最差 5% 交易日：黄金平均 −0.26%（胜率 48%），债券 +0.03%~+0.08%（胜率 62–66%）。

**结论**：黄金是**周期对冲**，债券是**急跌对冲**，红利**不是防御资产**。

## 3. 策略验证（第二、三轮）

### 3.1 单次样本内 → 样本外

- 7 个资产中，3 个直接选"买入持有"；4 个选了择时（中证500 + 3 只债券）。
- 这 4 个择时策略在样本外**全部跑输同资产持有**（−0.01 ~ −15pct）。
- 8 个通过样本内门槛的择时策略（含长期面板），样本外 **0 个跑赢持有**。

### 3.2 滚动验证（2 年训练 / 1 年测试）

| 面板 | 选择策略 | 持有 | 折胜率 |
|---|---|---|---|
| 2019+ 组合（5 折） | 6.25% | 6.21% | 1/5 |
| 2013+ 组合（10 折） | 6.61% | 9.20% | 1/10 |

**"选策略"本身没有 alpha**，偶尔的跑赢来自个别年份。

### 3.3 参数曲面（C 类：200 日线 + 回调）

| 资产 | 2019+ OOS 优于持有 | 2013+ OOS 优于持有 |
|---|---|---|
| 中证500 | 6/9 | 5/9 |
| 沪深300 | 0/9 | 1/9 |
| 中证红利 | 0/9 | 0/9 |
| 黄金 | 6/9（全样本 0/9） | 0/9 |

**只有中证500 存在连续稳定区域**，其余是单点噪声或行情产物。

### 3.4 淘汰清单

| 策略 | 原因 |
|---|---|
| 单均线（MA60/120/200）股票 | 样本外全负 |
| 波动率目标 | 15–21 次/年，费用 9%–35% 本金 |
| 估值过滤（PE 90% 减半） | 样本外明显低于持有 |
| 唐奇安（股票） | 样本外负收益 |
| 黄金过热减半 | 与持有无显著差异 |

### 4.3 参数稳定性

- **再平衡频率**（月/季/半年）：各配置年化差异 ≤0.4pct，Sharpe 差异 ≤0.05。
- **逆波动率波动窗口**（60/120/250 日，债券上限 40%）：
  - 全样本年化 7.68% / 7.79% / 7.82%，OOS 10.91% / 10.86% / 11.00%；
  - Sharpe 0.84–0.86 / 1.21–1.23；交易 167 / 96 / 85 笔。
- **固定权重 ±5pct 扰动**（30/35/15/20 的每个资产各加减 5pct，其余按比例吸收）：年化 7.38%–8.63%，回撤 −11.75% ~ −13.97%，Sharpe 0.59–0.72。**参数扰动不改变"回撤约 −12% 量级"的结论**，也不会让固定权重方案的风险特征接近逆波动率（−6.8%）。

### 4.4 为什么推荐逆波动率，而不是收益最高的配置

| | 30/35/15/20 | 逆波动率（≤40%） |
|---|---|---|
| 样本外年化 | 13.12% | 10.86% |
| 样本外回撤 | −12.66% | **−5.81%** |
| 样本外 Sharpe | 1.03 | **1.21** |
| 样本外 Calmar | 1.04 | **1.87** |
| 平均债券权重 | 20% | 40% |
| 依赖单一资产 | 黄金 30%、沪深300 35% | 最高 40% |

- 逆波动率用**更低的收益换来了不到一半的回撤**，并且权重由波动率决定、不是人为拍板，参数稳定性更好。
- 代价是它把 40% 放在债券上；如果未来利率上行，债券部分会拖累收益。这一点必须写进产品说明。
- **不建议**用"40/40/20"或"黄金+300各半"作为默认：它们的回撤达到 −16% ~ −20%，对 2000 元、且可能随时需要动用的资金池来说太大。

### 4.5 逆波动率的平均权重（不是固定值）

| 资产 | 平均 | 区间 |
|---|---|---|
| 黄金 | 22.3% | 9.1%–38.6% |
| 沪深300 | 17.8% | 10.3%–25.0% |
| 中证红利 | 20.2% | 11.1%–28.8% |
| 1-3年国开 | 39.7% | 25.0%–40.0%（多数时间触顶） |

权重每月按 120 日波动率重算；债券多数时间顶到 40% 上限，意味着实际是“40% 债券 + 60% 风险资产内部再分配”。最新一期（2026-10-21）为黄金 17.8%、沪深300 19.0%、红利 23.2%、债券 40.0%。

### 4.6 对照实验：完整协方差 ERC（是否值得替换简单方案）

**先更正命名**：4.1–4.5 的"逆波动率"就是 `w_i ∝ 1/σ_i`，没有用协方差矩阵，不是严格意义的"风险平价"。
真正的风险平价应使用完整协方差矩阵，使各资产的风险贡献相等（ERC）。下面用**同一历史数据、同一费率、同一样本外区间**做对照：

| 方案（债券上限 40%，120 日窗口） | 全样本年化 | 全样本回撤 | Sharpe | 样本外年化 | 样本外回撤 | 样本外 Sharpe | 交易 | 费用 |
|---|---|---|---|---|---|---|---|---|
| 逆波动率（现方案） | 7.79% | −6.83% | 0.846 | 10.86% | **−5.81%** | 1.208 | 96 | 9.65 |
| ERC（完整协方差） | **8.23%** | −6.61% | **0.916** | **11.77%** | −6.55% | **1.303** | 86 | 8.98 |
| ERC（债券上限 50%） | 7.39% | **−5.53%** | 0.938 | 10.43% | **−5.53%** | 1.356 | 73 | 8.81 |

**ERC 参数稳定性**（60/120/250 日，债券上限 40%）：

| 窗口 | 全样本年化 | 样本外年化 | 全样本 Sharpe | 样本外 Sharpe |
|---|---|---|---|---|
| 60 日 | 8.06% | 11.47% | 0.902 | 1.299 |
| 120 日 | 8.23% | 11.77% | 0.916 | 1.303 |
| 250 日 | 8.17% | 11.72% | 0.904 | 1.280 |

**判断：不采用 ERC，保留逆波动率。** 理由：

1. 改善幅度有限：全样本 +0.44pct、样本外 +0.91pct，Sharpe +0.07/+0.10；**回撤没有改善**（样本外 −6.55% vs −5.81%），Calmar 反而更低（1.80 vs 1.87）。
2. 4 个资产、120 日样本估计协方差矩阵，噪声大；引入求解器与边界投影，多了一套可能失效的环节。
3. 按"每增加一条规则都要证明复杂度值得"的原则，这点改善不足以支持替换。
4. ERC 结果已保存在 `out_alloc/stability_erc.csv`，作为对照保留；若未来资产数增加、或股债相关性结构变化，可重新评估。

## 5. 资金管理（第三轮实现，第四轮验收）

### 5.1 公式

```
pool_target = 总金融资产 × 10%
pool_value  = 池内现金 + 持仓市值 + 在途资金
new_allowed = max(0, pool_target − pool_value)
new_used    = min(new_allowed, 外部可用现金)
spendable   = 池内现金 + new_used
target_i    = w_i × (pool_value + new_used)
买入_i      = 按缺口比例分配 spendable，≥10 元
```

### 5.2 验收结果

`test_capital_pool.py`（9 项）+ `test_capital_pool_acceptance.py`（12 项）全部通过：

| 验收点 | 结果 |
|---|---|
| 10% 目标、允许新增额度 | 通过 |
| 池子超目标 → 暂停新增、不强制卖出 | 通过 |
| 卖出款 T+2 到账，当日不可买入 | 通过（含回款后可用） |
| 多买点资金不足 → 按缺口比例 | 通过 |
| 最小申购 10 元 | 通过 |
| 暂停申购 / 超日限额 / 缺净值 → 不生成建议 | 通过 |
| 7 天内赎回 1.5% | 通过（1000 元卖 3 天 = 15 元） |
| 持有期未知 → 保守费率 + 提示 | 通过 |
| 权重合计 >100% → 拒绝 | 通过 |
| 现金不为负 | 通过 |
| 相同输入 → 相同输出（可复现） | 通过 |

### 5.3 示例（2026-10-21，2000 元池）

- 逆波动率目标：黄金 356.50、沪深300 380.19、红利 463.31、债券 800.00；
- 费用 1.74 元；交易后现金 0.01 元。
- 若池子 2100 元（超目标 100）：暂停新增；卖出超配、买入低配只能用现有现金，卖出款 T+2 后再买。

详见 `out_wf/plan_demo.txt`。

## 9. 局限与"什么会改变结论"

1. 2019+ 样本只有 7.3 年，包含黄金大牛市与债券牛市；逆波动率的低回撤部分来自债券顺风。
2. 逆波动率的 40% 债券上限是人为约束；若不设上限，债券会占 60% 以上，收益更低。
3. 未覆盖 QDII 溢价、限购状态变化、渠道折扣差异。
4. 未模拟分红进入现金账户的再配置（按再投资处理）。
5. 如果未来 3–5 年出现"股债双杀 + 黄金下跌"，逆波动率也会亏；届时需要重新评估债券上限。
6. 如果 C 类在中证500 的影子记录连续 12 个月跑赢，且回撤更低，才考虑把它加入正式规则。
