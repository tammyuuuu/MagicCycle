# 简化实际基金与买入记录

2026-10-22，原导出器已更新 `docs/index.html`。

## 日常流程

- 资产区块的“选择基金 / 记录买入”打开同一个弹窗，只有基金、买入日期、买入金额三项。基金支持现有产品列表及六位代码查询，日期默认当天。
- 默认带入已选基金与可用参考金额，复用原计划、目标差额、现金及已有公开额度。金额仅供填写实际支付额，保存不代表系统下单；未核实归属的产品不自动给出目标资产买入建议。
- 删除合同链接、指数勾选、渠道、限额、状态、费率、最低申购额等审核控件及其渲染/提交代码，不再折叠保留。
- 名称优先来自版本化基金目录和美股监测；目录外产品查询现有东方财富公开基金源，要求代码、基金类别和基础资料代码精确匹配。没有仅凭基金代码、名称关键词或宽泛产品类型推断策略资产类别。
- 无法核实名称则不保存；能核实名称但不能核实资产归属时，允许独立记账，资产为待核实，不自动合并到纳指、标普等目标资产，不修改该目标的产品选择。
- 保存后为已提交/待确认，冻结实际支付金额，实际份额和费用保留未知值。公开净值不用于倒算用户份额，公开年费不当作渠道实际手续费。确认时仅补充实际确认日期、份额和实际费用；赎回确认/到账沿用原流程。
- 同指数且已有核实映射的南方与易方达持仓合并计算。原始交易仍按实际代码保存；同代码/同一已核实资产的待确认交易及同一提交ID均防止重复。
- 支持账本起始日至今天的实际买入日期。早于冻结期初的日期拒绝保存，不悄悄改写账本期初。
- 新查询产品保存真实公开净值；持仓后随账户净值刷新尝试更新公开数据。同日冲突保留原值并提示；历史净值缺失时继续暂停收益计算，不伪造历史曲线。

## 自动资料与边界

公开基金查询源：`https://fundsuggest.eastmoney.com/FundSearch/api/FundSearchAPI.ashx`。已只读核验精确代码查询及JSONP回调格式，静态入口可直接查询。无法提供的渠道额度、实际费用、成交份额保持未知；公开来源不能证明用户的渠道确认结果。

历史账本、手动核实过的旧产品映射、费用和资料均未删除；旧资料继续作为保存历史存在，新界面不再要求填写审核表。资金池、重放、申赎确认、修订、到账及备份格式未改变。
