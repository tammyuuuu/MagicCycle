# 星循 UI/UX 优化验收

完成日期：2026-10-22（Asia/Shanghai）。基于当前新版源码直接改造，未还原旧版代码。

## 本次修改文件

- `templates/_mobile_ui.html`：新增共用界面样式，460px 居中单列、底部导航、安全区、横向分类、触控尺寸和减少动画偏好。
- `templates/index.html`：动态入口引入共用样式。
- `templates/_invest_tools.html`：配置步骤与金额优先；复盘交易记录移到页面内；空状态简化。
- `investment_workspace.js`：预算展示、本月指标展示、策略折叠列表与按需绘图、按页保存滚动位置。没有修改规划器、估值器或账本核心计算。
- `export_alerts.py`：正式导出复用同一份界面样式。
- `docs/sw.js`：升级离线缓存版本，更新应用壳。
- `docs/index.html`、`docs/index.json`、`docs/account_nav.json`：使用现有导出器离线重新生成。
- `ui_optimization/`：改造前快照、截图、专项验收脚本与报告。既有测试生成的预览、截图和 JSON 位于 `workspace_ui_20261022/`。

## 测试结果

- 核心回归 15 组全部通过；Python 全套 185 个测试再次通过。
- `browser_acceptance.js`：Flask / 静态预览 / 正式入口 × 1440 / 375 / 320px，9 组全部通过。四页切换、无横向溢出、首次资产设置、预算、申购确认、赎回到账、资金流与收益分离、净值盈亏和 JSON 恢复均通过。
- `browser_def_monitor.js`：相同 9 组全部通过；ETF 分类、7 条美股渠道监测、A–F / L1–L4、两策略对比、历史区间、代理与真实基金分离、缺失历史清空曲线。新版测试先展开策略再验证配置文字。
- 原有 `browser_simple_plan.js`：3 个入口 × 桌面 / 375px 的手动决定、待确认份额、实时净值覆盖、策略持久化、分步申购及赎回流程通过。
- 正式 PWA：Service Worker 安装、应用壳缓存、离线重新载入及四页导航通过。沙箱曾阻止本机回环访问，使用获准命令完成真实离线测试。
- 截图验收：桌面内容宽度 ≤460px；375px、320px 四页无页面级横向溢出；策略展开后两张图正常。
- 专项检查发现折叠列表缺少数据不足提示，已补齐并通过复测；无阻断性回归。
