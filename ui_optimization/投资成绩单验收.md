# 投资复盘成绩单验收

2026-10-22，正式本地入口为 `docs/index.html`，通过原导出器更新。

## 成绩单

- 单个白色圆角主容器，依次显示策略状态与日期、投资账户总资产、本月与累计盈亏、累计收益率、最大回撤、已确认费用、目标/实际配置及两张曲线。
- 累计盈亏直接读取已修复估值器的 `cumulativePnl`（人民币）；回撤直接读取资金流调整后净值的 `drawdown`。没有修改、重新拟合或用回测曲线替代实际账本曲线。
- 目标配置来自已确认交易保存的目标权重；旧记录仅在关联版本完全匹配时读取其原研究权重。版本不匹配、没有关联或同日关联多个不同方案时，不猜测执行目标。
- 实际配置用实际基金确认份额和实际净值，按核实资产类别汇总，以投资账户净资产为分母；现金、冻结与应收单列。截图不显示个人总金融资产、交易ID或全部基金明细。
- 当前系统没有正式策略启用记录，也未启用任何正式策略。因此明确显示“未启用正式策略”。已确认交易关联的研究方案、首次关联日期及变更记录单独标注，曲线金色竖线标记对应日期；没有把研究下拉选择、待确认交易或模拟回测当作正式执行证据。
- 新交易继续保存原策略编号和版本，并新增当时的目标权重快照及手动交易来源标记。历史交易、修订和JSON数据不做覆盖迁移。
- 两图支持触摸、鼠标和左右键查看同一日期的人民币盈亏与百分比回撤；日期轴一致。
- 无确认投资或净值无效时，收益显示“—”，不生成虚假曲线。空仓现金或冻结款仍按真实账本显示账户资产。
- “截图视图”保留真实成绩单，隐藏固定页头、底部导航和其他操作控件；退出后恢复正常界面。可使用设备的长截图功能保存完整成绩单，不生成替代数据或独立网站。
- 交易记录、更正和撤销移至投资配置的原主容器中，继续操作同一笔记录；备份恢复仅保留成绩单外的轻量入口。
