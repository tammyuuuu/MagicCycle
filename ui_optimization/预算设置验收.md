# 投资配置预算流程验收

2026-10-22，使用原导出器更新 `docs/index.html`。

## 行为

- 新账户先输入总金融资产和投资比例，实时显示预算；比例默认10%，可选5%、20%或0–100%自定义。保存后显示策略选择和模拟计划。
- 首次保存沿用原账户规则：将目标预算登记为空仓期初现金，仅是本地账本分配，不会转账。日后修改预算不再次初始化账户，也不自动增加现金。
- 日常顶部显示目标预算、总资产、比例、统计日期、实际账户净资产、可用现金和可新增额度，提供“修改资产 / 比例”。每月可手动更新，未更新继续使用旧金额和已保存比例。
- 提高预算只增加允许转入的额度；实际资金转入仍须在高级管理手动登记。低于当前账户净资产时，可新增额度为零，不因下调预算强制卖出。原有池内资金仍按原资金池规则计算模拟配置。
- 策略卡片目标金额使用所保存的目标预算；可执行金额仍受真实账户现金、持仓、冻结、在途资金及产品条件约束，目标金额不代表现金已到账。
- 既有账户直接读取原总资产快照与档案比例，没有自动迁移、重建或覆盖账本。没有快照但已有期初的账户补录预算时，同样不会重新初始化。
- 原资金流、更正、撤销、JSON恢复仍在高级管理；预算设置不再放在高级管理内部。

## 文件

- `templates/_invest_tools.html`：首页初始化表单、比例输入及预算摘要。
- `investment_workspace.js`：流程状态、实时预览、持久化设置、首页修改入口及按保存比例校验转入。
- `asset_planner.js`：接收真实总资产和保存比例，复用原资金池引擎计算目标及可新增额度。
- `portfolio_store.js`：预算比例校验允许0%，保留既有存储和备份格式。
- `purchase_monitor.js`：预算参考同步使用保存比例，去掉固定10%及未设置时的虚构默认资产。
- `docs/index.html`、`docs/index.json`：原导出器产物；`docs/sw.js`更新缓存版本为v8-budget-setup。
- `ui_optimization/browser_budget.js`：新增首次设置、修改、冻结保护、月度沿用及恢复测试。
- 现有配置/产品浏览器测试适配首次使用流程；`run_tests.py`纳入新预算测试。
