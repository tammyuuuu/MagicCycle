# 购买渠道与债券观察

2026-10-14新增；依用户要求不监测货币基金，不增加新的股票行业标的。

每日开机的MagicCycleAutoUpdate.vbs调用update_alerts.ps1，后者运行export_alerts.py。导出时purchase_monitor.update_snapshot读取qdiilimit.com当日额度汇总，并按基金代码从东方财富基金历史净值接口读取最新披露值；生成purchase_monitor.json，嵌入同一次生成的HTML。启动发布脚本提交并推送index.html、index.json、purchase_monitor.json。手动refresh_local也经同一导出入口更新。

观察名单：021000南方纳指I（官方直销）、019441万家纳指A（官方直销与代销）、022525天弘纳指D（指定代销）、017641摩根标普A、022523天弘标普D、006484广发中债1—3年国开债指数A。

美股额度来自第三方公开公告汇总，不是登录渠道实测；必须标明来源日期、直销/代销不同限制及公告备注，A/C合并额度不可重复算。来源日期不是运行当天时，不将其显示为当日额度。保留已公告未来生效的变化，避免仅凭今天额度推荐即将关闭产品。抓取失败记录缺失，不填0、不默认可买。

净值/披露日申购状态不等于当日交易状态。年费为本次核对的资料参考，非自动实时费率抓取，优惠及申赎成本以产品资料为准。天弘标普D属于主动QDII-FOF，单独标明，不能等同纯被动ETF。国开债仅配置观察，有利率风险、净值可能下跌，不替代应急资金。

本模块独立于原TARGET_ETFS与股票信号，不纳入相关性池和月预算自动配比，不生成未经研究的债券买卖点。首次已实抓5项当日额度、6项最新净值。测试覆盖渠道区分、未来公告、旧日期拒绝、净值异常、货币基金排除以及静态导出更新连接。
