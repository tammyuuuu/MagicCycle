中证500：低估优先，估值不过高时跟随120日趋势。将趋势入场的PE分位上限从90%降为60%，减少估值偏高时追入。2014—2026年固定10万元条件模拟收益约246%、最大回撤58%；上一版本约217%、59%，持有约151%、66%。每月1000元的利润/本金由59%升至70%，普通定投约43%。

第一轮531组及追加192组探索中，严格趋势保护降低回撤但损失收益，前段首选在后段失效，未采用。新版本在逐月3/5年起点、较高交易成本和小额资金检查中改善，但回撤下降有限；低估仍可直接买入，邻近周期并不都有效。这是事后选择的试行方案，5年后段只有9个重叠起点，不能称为最优或未来保证。
