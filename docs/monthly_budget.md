# 月预算执行规则

输入全体所选ETF共用的月预算，固定标的集合，每只获得等额上限。第一次实际买入后锁定本月预算和标的，不按当天可买标的重新分配，否则重复计算可能持续抬高投入。个股暂不参与。

本次金额 = max(0, 该ETF月额度 × 当前信号档位 − 当月该ETF实际买入金额)，并受全账户剩余月预算限制。买入50%、加仓100%、小额尝试25%、配置50%、试探10%；观察、减仓、退出不配置新资金。重复信号只补差额，计算和保存建议不代表成交。未使用额度留现金，不自动累计到下月；已有持仓按原退出规则处理。

实际成交依赖当前浏览器投资日记，买入及加仓计入支出，卖出不恢复额度，其他标的实际买入也扣减总月额度。缺失或格式错误的记录不能推定成交。日记删除会相应改变剩余额度，需保持真实完整。预算保存在 monthly_budget_v1_YYYY-MM；日记仍可用原导出功能备份。预算暂不随日记导出或跨设备同步。

行情须与最近应已收盘日相符并通过现有数据和风险检查。美股溢价由浏览器自动读取东方财富 push2delay 的价格 f2、参考净值 f441、行情更新时间 f124，按价格/IOPV−1计算，避免把接口的折价率直接当作溢价率。展示时间和延迟口径；开页、切回页面或点击刷新时获取。刷新失败清除旧数据，不把缺失值当作0；仅接受当日数据，盘中更新不得超过20分钟，开盘前暂停。该时间为供应商行情更新时间，并非单独验证的IOPV更新时间。IOPV为参考估值，存在时差与估值误差，不能视为实时公允净值。

溢价超过2%或无有效自动数据时暂停新增；2%为保守执行试行上限，未回测证明最优。金额需预留佣金、按真实限价和100份单位换算，模块不会自动下单。浏览器跨域已验证供应商对本站Origin响应允许；接口不可用时保守暂停。后台刷新原行情快照的方式不变。

此规则控制支出，不承诺收益最优。未对预算配比或未用现金滚存开展新回测。Flask与静态导出共用 monthly_budget.js，通过 correlation_data.investment_script 嵌入；已导出的旧页面需重新导出才会包含新功能。
