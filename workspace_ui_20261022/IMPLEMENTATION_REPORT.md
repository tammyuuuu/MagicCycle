# 星循四页改造与验收

日期：2026-10-22。本轮在现有Flask与静态导出结构上改造，未重建站点；未提交、推送、发布或进行真实交易。

## 四页结果

### 今日提醒

保留原ETF买卖点、沪深300/中证500估值观察、持仓判断及刷新流程。增加“原ETF信号，不是新组合实盘指令”的标记。ETF策略计算、行情采集和定时推送脚本未改动。个股入口和页面区块隐藏，底层仍保留，避免影响共享依赖；本轮未物理删除旧代码。

### 投资配置

使用 `real / strategy` 独立账本，不读取旧ETF持仓、v1日记或 `real / manual` 持仓。进入页面不会自动产生2000元资产，必须先确认总金融资产，再明确确认空仓期初现金；默认表单值不是已入账金额。

展示总资产、10%资金池目标、现金、冻结款、应收款、确认份额和净值日期。月度总资产未更新时沿用上次金额并显示日期；超额标记暂停新增，不强制卖出。

手工记录支持申购提交→份额确认、赎回提交→确认应收→实际到账，以及失败、撤销、修改、删除和完整重算。这里只记实际操作，不连接下单渠道。基金代码需要明确选择，不默认替用户选基金。

候选配置展示权重与目标参考金额，按分分配且合计精确；没有可执行买卖差额或“立即买入”按钮，未调用资金池下单规划。新账户 allocationId 为空，正式策略没有启用。

### 投资复盘

旧投资日记表单已退出页面装配，改为自动账户复盘，交易录入放在投资配置。

- 每日净资产包含现金、申购冻结款、确认持仓、赎回应收和分红应收，不重复计值。
- 每日盈亏 = 当日净资产 − 上日净资产 − 当日外部净流入；月度直接汇总每日损益。
- 收益率按日初资金流调整，展示累计盈亏、累计收益率、日度最大回撤、实际确认手续费、月表、日表和交易历史。
- 手续费已经包含在净资产变动中，只单独展示，不重复扣除。
- 采用确认日入账口径；未确认申购按冻结成本暂估并标记待确认，不冒充经济成交日回溯的托管对账单，也不提前虚构持仓。
- 使用基金原始单位净值，研究总收益指数不进入真实账户估值。
- 分红按登记日确认份额确定权益，除息日计应收；实际现金到账或实际红利再投资份额另行确认。不把分红算作外部入金。与权益不匹配时停算，避免虚构收益。
- 节假日按已有代理日历处理；异常缺数停算。沿用此前净值时逐日标记，并提示不是全部当日最终收益。
- 完整JSON备份包含账户基线、源交易、资金流、分红确认、到账记录、修订历史和快照。恢复只允许同类型、同id的空账户，禁止覆盖已有记录。旧记录另有只读导出入口。

### 策略实验

从 `workspace_data/manifest.json` 指向的版本化文件读取A/B/C/L1/L2的权重、CAGR、MDD、区间、费用和逐日曲线，前端没有硬编码历史收益数字。

正常纳指申购和纳指不可买分组展示。对照工具支持同情景、跨情景、主样本/长期代理/2023历史分段，以及再平衡与简单持有；跨情景明确不作公平排名。也可选择同一方案，直接比较再平衡与持有。

展示归一化净值曲线和日度回撤曲线，保留被推翻结论及失败原因。所有方案标记为研究/模拟、条件性历史复现，未实盘验证。

## 数据流

```
手工确认记录 + 固定期初 + 外部资金流 + 实际到账
                         ↓
             portfolio_store 纯重放账本
                         ↓
原始单位净值/分红事件 → portfolio_valuation 日度估值
                         ↓
             每日/月度损益、收益、回撤和费用

修正后的统一日度引擎 results/*.csv + manifest
                         ↓
                build_workspace_data.py
                         ↓
       workspace_data/manifest.json → 带来源指纹的JSON
                         ↓
       Flask/静态共用装配 → 只读策略实验与候选参考金额
```

研究结果、模拟与真实账本不互相写入。数据打包只包含公开基金资料及研究产物，不包含用户账户数据。来源摘要与源文件指纹进入版本；同版本不同内容会拒绝覆盖。

## 使用及边界

正常本地启动仍为 `python -B app.py`。离线预览副本为 `static_preview.html`；浏览器测试已实际验证该生成链。

复现命令：

```powershell
python -B build_workspace_data.py
python -B workspace_ui_20261022/run_checks.py
python -B workspace_ui_20261022/build_previews.py
node workspace_ui_20261022/browser_acceptance.js
```

净值当前来自已保存的研究快照，最新资料日期为2026-10-21，各基金日期可能不同；未新增实时场外净值或个人渠道确认接口。后续净值源更新后重新打包才能延长可核对期间，页面不会把陈旧资料当实时行情。

现金按未投资现金处理，不虚构余额宝收益。实际分红须核对确认记录；历史发布时刻、限购和渠道费率仍是研究限制。账本以日期为主要粒度，同日回款与再次下单若缺少可核对先后顺序，会保守拒绝透支；部分确认需要按实际分笔记录。

所有策略仍处于研究/模拟状态。此次完成界面与账务接入，不代表策略获准实盘运行。
