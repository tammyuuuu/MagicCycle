# 投资配置页面简化验收

已将现有页面改为：研究策略选择 → 今日模拟计划 → 自动现金/持仓汇总 → 待确认/待到账 → 折叠高级管理。沿用深蓝、金色、米白色，无新增导航。

## 使用流程

- 首次确认一次总金融资产，默认20,000元，10%预算2,000元；自动记录当天开始日期，以预算现金、零份额建立账户。这里只做账本分配，不会在支付渠道转账。既有账户不重新初始化或覆盖。
- A/B/C与L1/L2/L3/L4均可作为研究情景选择；选择保存在账户的researchSelection中，正式allocationId和正式配置不变。
- 按目标权重、已确认持仓、冻结款及实际可用现金计算模拟金额。待确认申购只在计划里作为目标敞口投影，绝不写成实际份额；同一基金有待确认交易时不重复提供提交操作。
- 点击“记录已提交”，明确确认已在渠道自行提交。系统只登记账本；申购现金冻结，赎回申请份额保留。
- 基金确认后，申购只需补实际份额；赎回补确认净回款。费用预填保存费率的估算值，须与渠道核对；日期默认当天，可以展开修改。
- 赎回确认后仍显示应收；实际到账时确认实际金额，才增加可用现金。到账金额更正和到账事件一次保存，失败不留下半次更新。
- 首页不再展示期初现金、资金流与完整交易状态表单。每月提醒更新总资产；资金流、更正/撤销、期初例外登记在高级管理中。交易历史及JSON备份恢复沿用投资复盘入口。

## 金额与边界

复用CapitalPool与现有账本/估值模块。以现有账户净资产计算权重，2%偏离带、最低10元，不自动补预算、不复用未到账赎回款。策略切换会纳入新账户中不再配置的基金；历史旧账户始终不导入。

交易条件来自版本化数据中的保存快照，显示日期、限购和费用估算。暂停、未知或非当天的申购状态会阻止新增申购登记；限额扣除当天已提交和确认的申购，不按单笔反复使用日额度。快照失效后需更新数据，不能把它视为实时渠道可买性。没有投资机会的现金保持现金，不自动购买货基或虚计利息。

全部计划为研究/模拟情景，没有将研究策略批准为实盘策略。用户自行完成渠道操作后才手工登记真实账本；本次验收仅使用隔离浏览器中的合成测试账户。
